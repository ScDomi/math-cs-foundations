# Language map

This repo is also meant to show that the foundations work was not only Python.

| Language | Where | What it shows |
|---|---|---|
| Python | `src/foundations/`, `original_projects/Suchalgorithmen`, `original_projects/Turmites`, `original_projects/VierGewinntKI` | Importable algorithms, tests, CLI demo, search algorithms, cellular automata and game-AI experiments. |
| Java | `original_projects/PrimeGenerator`, `original_projects/TicTacToeAI` | Maven-style coursework projects with tests, prime sieves and object-oriented game AI. |
| Prolog | `original_projects/SudokuSolverProlog` | Constraint logic programming with CLP(FD), Sudoku solvers for 4x4, 6x6 and 9x9 boards. |
| C++ | `original_projects/cpp_oop_inventory` | Typed object modeling, inheritance, smart pointers, file parsing and export logic in a compact inventory-domain exercise. |

## C++ framing

The C++ project is intentionally not sold as a large warehouse application. It is included as a language-fundamentals example: a small domain that makes OOP boundaries, inheritance, parser logic and file I/O visible without pretending to be production software.
