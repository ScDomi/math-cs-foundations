# Tic-Tac-Toe Spiel mit intelligentem Computer

## Beschreibung

Dieses Projekt implementiert ein einfaches Tic-Tac-Toe-Spiel in Java. 
Außerdem wurde ein schlauer Computergegner durch den MiniMax-Algorithmus implementiert.

## Funktionalitäten

- Spieler gegen Computer
- Möglichkeit, den Computergegner zu wählen (zufällige Züge oder einfachere Heuristik)
- Konsolenausgabe des aktuellen Spielfelds
- Überprüfung auf Gewinnbedingung und Unentschieden
- Computergegner ist Schwierigkeitsstufe schwer

## Versionen der technischen Vorraussetzungen

- OpenJDK 21.0.1 2023-10-17
- OpenJDK Runtime Environment Homebrew (build 21.0.1)
- OpenJDK 64-Bit Server VM Homebrew (build 21.0.1, mixed mode, sharing)
- IntelliJ IDEA 2023.3.2 (Ultimate Edition)
- Builttool: Maven

## Verwendung

1. Öffnen sie das Projekt in einer IDE (IntelliJ wurde bei der Erstellung verwendet)

2. Führen Sie die Main-Methode in der Klasse Runner aus.

3. Auf der Konsole wird nun das Spiel angezeigt. Standardmäßig spielen Sie gegen einen schlauen Computer.
